React Task : 06-01-2025

*Create a Todo App where users can*:
	1.Add new tasks.
	2.Mark tasks as completed using a checkbox.
	3.View tasks with their completion status styled appropriately.
	
*Key Requirements*:
	1.Parent Component (TodoApp):
		- A form with an input field and a button to add new todos.
		- A list to display all todo items.
		- State management for todos and the form input.
	2.TodoItem Component:
		- Displays an individual todo with:
		- A title.
		- A checkbox to mark it as completed or not.
		- Receives props from the parent component.
	3.TodoTitle Component:
		- Displays the todo title.
		- Applies a line-through style for completed tasks.
	4.	CSS Styling:
		- Basic styles for the app layout, input form, button, and todo list.

*Note:* 
	Use useState only
